# 명리 해석 사전 (interpretation.md)

평생사주 챕터를 **근거 있고 일관되게** 쓰기 위한 해석 레퍼런스. 모든 문장은 이 사전 + 엔진(`manse.cjs --json`) 데이터에 묶여야 한다. 여기 없는 일반론(별점·혈액형 류)은 쓰지 않는다.

> **소수점 절대 금지.** 강약은 `counts.*`(개수·등급)로만 말한다. "재성 0.9" ❌ → "재성 1개·약함" ✅. (자세히는 SKILL.md 강약 표현 규칙)

---

## 0. 정통 감명 순서 & 궁위(宮位) — 모든 장의 뼈대

### 인기 풀이의 감명 순서 (이 논리로 결론 도출)
일간 → **신강/신약**(저울) → 오행 균형(없는 오행) → 십신 구조(없는 십신) → 격국·용신(평생의 약) → 신살·형충 → 대운/세운. **신강/신약이 모든 해석의 저울**: 신강이면 식상·재성·관성이 길(빼줌), 신약이면 인성·비겁이 길(채움).

### 궁위(자리)론 — 어느 기둥에 있느냐로 영역을 본다 (인기 핵심)
같은 십신·오행도 **어느 기둥**에 있느냐로 인생 영역이 갈린다. 엔진 `manse.{year,month,day,hour}` 위치로 판단:

| 기둥 | 자리(궁) | 인생 영역 / 시기 |
|---|---|---|
| 연주(年) | 조상·뿌리궁 | 조상·집안 분위기, 초년(0~15세), 사회 첫인상 |
| 월주(月) | 부모·사회궁 ★제일 중요 | 부모·형제, 직업·사회활동, 청년기(16~30대), 월령=사주의 계절·격국 토대 |
| 일주(日) | 자기·배우자궁 | 일간=나, 일지=배우자·내면, 중년기(30~40대) |
| 시주(時) | 자식·말년궁 | 자녀, 말년(50대~), 노후·결실 |

- 예: 재성이 **월지**에 있으면 직업으로 돈, **일지**면 배우자 덕/돈, **시주**면 말년 재물·자식 덕.
- 배우자운(제11장)은 **일지**가 1순위 단서. 자식운(제14장)은 **시주**.

## 2. 오행 강약·과부족 (제3장)

**엔진 `counts.ohaeng`(개수)와 `counts.ohaengGrade`만 사용.** `result.ohaeng`의 소수점은 내부 가중치 — 사용자에게 절대 인용 금지. 강약은 "○개", "없음/약함/보통/강함/과다", "가장 강한/없는 오행"으로만 표현.

- **과다 오행**(3개 이상) → 그 기운의 부작용이 인생 테마. **없는/약한 오행**(`counts.lacking`) → 평생 보충 과제.
- **"없는 오행" 풀이는 인기 사주의 최고 떡밥**(예: "물이 없는 사주는 융통성·여유를 의식적으로 길러야", "화가 없으면 표현·추진의 불씨가 약해 따뜻함을 더해야"). 없는 오행이 있으면 제3·12·17장에서 비중 있게 다룬다.
- 오행별 키워드: 木=성장·기획·인정욕 / 火=표현·열정·명예 / 土=안정·신뢰·중재 / 金=결단·규율·재물 / 水=지혜·유연·욕망.
- 보충법(개운, 제17장 연결): 부족 오행을 색·방위·음식·환경으로 보강.
  - 木: 청록색, 동쪽, 나무/식물, 신맛 / 火: 빨강, 남쪽, 빛·온기, 쓴맛
  - 土: 노랑·황토, 중앙, 흙·도자기, 단맛 / 金: 흰색, 서쪽, 금속, 매운맛
  - 水: 검정·남색, 북쪽, 물, 짠맛

### 오행 ↔ 건강(장부) 매핑 (제12장)
부족하거나 과다해 깨진 오행을 장부 약점으로 연결. **"약한 장부·관리 포인트"까지만, 중병 단정 금지.**

| 오행 | 장부 | 약하거나 깨질 때 관리 포인트 |
|---|---|---|
| 木 | 간·담·근육·눈 | 피로·눈·근육 긴장·스트레스성 |
| 火 | 심장·소장·혈압·정신 | 심혈관·불면·심리기복 |
| 土 | 비위·소화기 | 소화·위장·당대사·식습관 |
| 金 | 폐·대장·기관지·피부 | 호흡기·피부·면역·알레르기 |
| 水 | 신장·방광·생식·뼈 | 신장·비뇨·체력·골격·호르몬 |

## 3. 십신(十神) 10종 — 에너지 지도 (제4·8·9·11·14장 전반)

**강약은 `counts.shipsinGroup`/`counts.shipsinDetail`(개수)로만.** 소수점 `result.shipsin` 인용 금지. "재성이 2개라 …", "관성이 없는 사주는 …", "식상 과다라 …" 처럼 개수로 말한다. 위치는 기둥별 `manse.*.stemShipsinKo/branchShipsinKo`로 확인(어느 궁에 있나).

- **"없는 십신"(`counts.missingShipsin`)도 핵심 떡밥**: 무재성(돈에 초연·고정수입형), 무관성(자유로움·조직 답답함, 여자=배우자 인연 늦음 경향), 무인성(독학·자수성가·문서운 약), 무식상(표현·재능 발산 막힘), 무비겁(독립심·내 편 적음). 단정 말고 "경향"으로.

| 십신 | 묶음 | 의미 | 강할 때 | 약/없을 때 |
|---|---|---|---|---|
| 比肩 비견 | 비겁(자아) | 동료·경쟁·독립 | 주관·추진·자수성가 | 의존·줏대약 |
| 劫財 겁재 | 비겁 | 경쟁·동업·승부 | 배짱·돌파 | 재물누수·구설(과다시) |
| 食神 식신 | 식상(표현) | 표현·생산·여유 | 재능·먹복·낙천 | 무기력·표현막힘 |
| 傷官 상관 | 식상 | 재능·끼·반항 | 창의·언변·스타성 | 답답·인정욕 결핍 |
| 偏財 편재 | 재성(재물) | 유동재물·사업·스케일 | 사업수완·재테크·인복 | 돈관념 약·기복 |
| 正財 정재 | 재성 | 고정수입·성실·실속 | 알뜰·신용·안정재물 | 돈모으기 힘듦 |
| 偏官 편관(칠살) | 관성(통제) | 압박·도전·권력 | 추진·결단·위기돌파 | 끈기·조직력 부족 |
| 正官 정관 | 관성 | 명예·직책·규율 | 신뢰·승진·반듯함 | 책임회피·자리불안 |
| 偏印 편인 | 인성(수용) | 직관·전문·비주류학문 | 통찰·기술·연구 | 변덕·게으름 |
| 正印 정인 | 인성 | 학문·문서·보호 | 공부복·귀인·자격 | 결정장애·의존 |

**축약 해석 키**:
- 재성(편재+정재) = 재물·아버지·(남)여자. 강약으로 **재물운(제8장)** 톤 결정.
- 관성(편관+정관) = 직장·명예·(여)남편·(남)자식. **직업운(제9장)·결혼운(제11장)** 핵심.
- 인성(편인+정인) = 공부·문서·어머니·귀인. **학업운(제10장)**.
- 식상(식신+상관) = 표현·재능·(여)자식·사업감각.
- 비겁(비견+겁재) = 나·형제·동료·경쟁. 과다하면 재물 깨짐(군겁쟁재).

## 4. 격국(格局) & 용신(用神) (제5·6장)

- `kyukguk`(예: 식신격·정관격·편재격…) = 사주를 끌고 가는 대표 기운 = **삶의 운영 방식/그릇의 결**. 격 이름의 십신 성질로 "이 사람이 세상을 대하는 메인 무기"를 설명.
- `yongshin.ohaeng` + `reason`(신강→설기/신약→부조 등) = **평생 나를 살리는 기운**. 용신 오행을 색·방위·계절·직업방향으로 환산해 제6·17장에 활용.
  - 신강(身强): 내 기운이 강함 → 빼주는(설기) 식상·재성·관성이 약. 도전·표현·재물 활동이 길.
  - 신약(身弱): 내 기운이 약함 → 채워주는(부조) 인성·비겁이 약. 공부·휴식·내 편 만들기가 길.

## 5. 대운(大運) — 인생 그래프 (제7·16장)

엔진 `daewoon` 배열(10년 단위 간지+시작나이). 각 대운 간지를 **일간/용신과 대조**해 길흉 흐름을 그린다.

- 대운 천간·지지의 오행이 **용신과 같은 기운** → 상승·황금기. **용신을 극하는 기운** → 정체·조심기.
- 서술법: "○○세(○○년~)부터 ○○ 대운 — 천간 ○(○행)이 용신을 ○하니 …한 시기". 유년·청년·중년·노년으로 묶어 인생 그래프처럼.
- 제16장 길흉 캘린더는 대운 중 **가장 좋은 구간 2~3개 / 조심할 구간 1~2개**를 명시.
- 세운(올해): 해당 연도 간지를 일간과 대조. 정확히 보려면 그 해를 엔진에 넣어 확인(예: 올해 운세 질문 시).

## 6. 12운성(十二運星) (제15장 보조)

엔진 `manse.*.unseong`. 각 기둥 기운의 생애주기 단계 = 그 영역의 에너지 강도.

장생(태동) · 목욕(시행착오) · 관대(성장) · 건록(전성) · 제왕(절정) · 쇠(하강) · 병(약화) · 사(정체) · 묘(저장) · 절(끊김) · 태(잉태) · 양(양육).

- 일지 운성 = 내 본질 에너지 단계. 건록·제왕이면 주체성·기세 강, 절·묘면 내향·축적형.

## 7. 주요 신살(神殺) (제15장 핵심)

엔진 `manse.*.shinsals` 에 잡힌 것만 풀이(없으면 억지로 만들지 않음). 대표 의미:

|---|---|---|
| 도화(挑花) | 매력·인기·이성연 | 끼·인기복(긍정)·구설 주의 |
| 역마(驛馬) | 이동·해외·변동 | 활동·여행·이직·글로벌 |
| 화개(華蓋) | 예술·종교·고독·학문 | 재능·몰입·정신세계 |
| 천을귀인(天乙貴人) | 최고 길신·귀인 | 위기 때 돕는 사람·행운 |
| 문창(文昌) | 학문·시험·총명 | 공부·자격·문서운 |
| 양인(羊刃) | 강한 기세·칼 | 추진·승부(과하면 충돌) |
| 백호·괴강 | 강렬·극단 기운 | 카리스마·전문직(과하면 기복) |

### 12신살 (엔진 `manse.*.sibiShinsal`, `result.sibiShinsal`)

기준 지지(연지 또는 일지)의 삼합 그룹에서 겁살부터 순서대로 붙는다. 연지 기준이 전통·인기 앱 표준이고, 일지 기준은 본인·배우자 관점 보조로 쓴다. 두 기준이 다르면 연지 기준을 먼저 말하고 일지 기준을 덧붙인다.
대운·세운 지지의 12신살은 `result.sibiShinsal.byYear.table[지지]`로 조회한다.

| 12신살 | 의미 | 긍정적으로 쓰면 | 주의 |
|---|---|---|---|
| 겁살(劫殺) | 빼앗김·외부 압박 | 위기 돌파력, 승부사 | 손재·강탈, 무리한 경쟁 |
| 재살(災殺) | 갇힘·재난 | 집중력, 전문직(법·의료·보안) | 송사·구속, 사고 |
| 천살(天殺) | 하늘의 뜻·불가항력 | 종교·철학·정신세계, 윗사람 덕 | 천재지변처럼 손쓸 수 없는 일 |
| 지살(地殺) | 땅에서 출발·터전 이동 | 독립, 이사·이직·유학, 활동 반경 | 잦은 변동, 마무리 약함 |
| 연살(年殺) = 도화 | 매력·인기·이성 | 인기, 예술·서비스·대인업 | 이성 구설 |
| 월살(月殺) | 마름·고갈 | 절약, 기초를 다지는 끈기 | 일이 막힘, 기운 소진 |
| 망신살(亡身殺) | 드러남·체면 손상 | 대중 노출, 솔직함 | 구설·실수 노출 |
| 장성살(將星殺) | 장수의 별·주도권 | 리더십, 조직 장악 | 고집, 독단 |
| 반안살(攀鞍殺) | 말안장에 오름·승진 | 출세, 안정된 지위, 귀인 | 거의 길신 |
| 역마살(驛馬殺) | 먼 이동·변화 | 해외·출장·무역·운전 | 정착 어려움 |
| 육해살(六害殺) | 은근한 손상 | 섬세함, 의료·상담·간병 | 잔병·신경 소모 |
| 화개살(華蓋殺) | 덮개·예술·고독 | 학문·예술·종교, 몰입 | 고독, 외골수 |

신살은 **양념**이다. 명식 본체(일간·십신·격국) 해석을 신살이 보조하도록 쓴다. 신살만으로 겁주지 않는다.

## 8. 육친(六親) 대응 (제11·14장)

십신을 가족으로 환산. 성별로 다름:
- 인성 = 어머니 / 재성 = 아버지.
- 남자: 재성 = 아내·여자 / 관성 = 자식.
- 여자: 관성 = 남편·남자 / 식상 = 자식.
- 비겁 = 형제·자매·친구·동료.

해당 십신의 강약·위치(특히 일지=배우자궁, 시주=자식궁)로 가족운·배우자상을 푼다.

## 9. 금지·주의 (모든 장 공통)
- 수명·사망·불치병 확정, 임신/낙태 단정, 이혼/파산 확정, 투자종목·법적 판단 **단정 금지**.
- 부적·굿·비싼 개명 **강매 금지** — 개운은 무해한 색·방위·습관·방향까지만.
- 타인 사주를 본인 동의 없이 단정하지 않기. 궁합은 "경향·포인트"로.
- 모든 풀이 끝에 "참고이며 인생은 본인 선택으로 바뀐다" 취지의 면책 한 줄.
