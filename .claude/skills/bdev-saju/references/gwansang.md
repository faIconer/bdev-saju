# 관상 해석 사전 (gwansang.md)

`engine/gwansang.py --json` 결과의 **등급**을 해석으로 바꾸는 규칙집.
사주의 `interpretation.md`와 같은 역할이다. 모든 관상 문장은 **엔진 등급 + 이 사전**에 묶여야 한다.

> 전제: 관상은 과학적 근거가 없는 전통 문화다. 재미와 자기성찰용으로 풀고, 사람을 평가·차별하는 근거로 쓰지 않는다.

---

## 0. 표현 규칙

- **숫자 금지**: `ratios`, `percent`는 내부 측정값이다. 사용자에게 "상정 21%", "비율 1.13"처럼 말하지 않는다. 등급(짧음/보통/김 등)으로만 말한다.
- **"보통"은 흠이 아니다**: 관상에서 균형은 최고 덕목이다. 보통이 많으면 "치우침 없이 고른 상"으로 좋게 푼다.
- **나쁜 등급도 양면으로**: 모든 특징은 장점과 주의점을 함께 쓴다. 단정·비하 금지.
- **측정 한계 고지**: `warnings`가 있으면 풀이 맨 위에 알린다. `notMeasured`(귀·기색·점·주름)는 사진을 보고 눈으로 보완하되 "사진상으로는"이라고 밝힌다.
- **금지 영역**: 수명·질병 단정, 범죄성·지능·도덕성 판정, 인종·외모 비하, 성적 매력 평가. 건강은 "관리 포인트" 수준까지만.

## 1. 삼정(三停) — 인생 시기

| 구간 | 부위 | 시기 | 담당 |
|---|---|---|---|
| 상정 | 이마 (발제선~미간) | 초년 (~30세) | 부모 덕, 학업, 지혜 |
| 중정 | 미간~코밑 | 중년 (31~50세) | 자수성가, 사회 활동, 재물 |
| 하정 | 코밑~턱끝 | 말년 (51세~) | 자녀·아랫사람, 안정, 노후 |

- **세 구간이 모두 보통** → 삼정균등. 관상에서 가장 좋게 보는 구조. 인생 굴곡이 적고 시기마다 고르게 풀린다.
- `longest`가 가리키는 구간 → **그 시기에 운이 가장 두텁다**.
  - 상정이 김: 초년 복, 공부 운, 부모 덕. 머리로 먹고사는 일.
  - 중정이 김: 30~40대 전성기. 스스로 일으키는 힘. 사회적 성취.
  - 하정이 김: 늦게 피는 복. 말년 안정, 아랫사람 덕, 부동산·터전.
- **짧은 구간** → 그 시기에 스스로 채워야 할 몫. (예: 상정 짧음 = 초년에 기댈 곳이 적어 일찍 자립)
- ⚠ 엔진의 상정은 발제선이 아닌 이마 위쪽까지만 잰다. 사진상 이마가 넓게 보이면 눈으로 보완한다.

## 2. 얼굴형 오행

엔진 판정 기준(`faceShape.ohaeng`)과 전통 의미:

| 형 | 엔진 기준 | 모양 | 기질 |
|---|---|---|---|
| 목형(木) | 얼굴이 길고 위아래 폭이 비슷 | 길쭉, 곧음 | 학자형. 인자하고 곧다. 성장·기획·교육 |
| 화형(火) | 이마가 넓고 턱이 뾰족 (역삼각) | 위가 넓고 아래가 좁음 | 예술·표현형. 열정적, 두뇌 회전 빠름. 기복 주의 |
| 토형(土) | 턱이 넓고 두툼, 얼굴이 짧은 편 | 넓적, 두터움 | 신용·중재형. 묵직하고 믿음직. 부동산·관리 |
| 금형(金) | 턱이 각지고 위아래 균형 | 각진 사각형 | 원칙·결단형. 의리, 추진력. 조직·법·금융 |
| 수형(水) | 짧고 둥글며 턱이 부드러움 | 둥글, 통통 | 지혜·사교형. 유연하고 눈치 빠름. 무역·유통·소통 |

- `secondary`도 같이 푼다. "금형 바탕에 목형 기운이 섞인 얼굴"처럼.
- 판정은 사진 각도에 따라 흔들린다. 사진 속 얼굴이 판정과 명백히 다르면 눈으로 본 판단을 우선하고 그렇다고 밝힌다.

### 사주와 엮기 (bdev-saju 전용)

사주 명식이 있으면 **얼굴형 오행과 일간 오행**의 관계를 본다.

| 관계 | 예 (일간 金 기준) | 의미 |
|---|---|---|
| 같은 오행 | 금형 | 겉과 속이 같다. 기질이 뚜렷하고 일관된다 |
| 얼굴이 일간을 생함 | 토형 (土生金) | 외모·인상이 나를 받쳐준다. 첫인상 덕을 본다 |
| 일간이 얼굴을 생함 | 수형 (金生水) | 속을 겉으로 풀어낸다. 표현력이 좋지만 기운 소모 |
| 얼굴이 일간을 극함 | 화형 (火剋金) | 겉과 속이 다르게 보인다. 오해받기 쉬우나 단련되는 상 |
| 일간이 얼굴을 극함 | 목형 (金剋木) | 속이 겉을 누른다. 절제력, 감정을 잘 안 드러냄 |

추가로 **용신 오행과 얼굴형이 같으면** "얼굴에 용신을 지니고 태어난 상"으로 좋게 본다.

## 3. 오관(五官)

### 눈 — 감찰관(監察官). 마음의 창
| 항목 | 등급 | 풀이 |
|---|---|---|
| 눈_크기 | 큼 | 감수성·표현력, 개방적. 감정이 얼굴에 잘 드러남 |
| | 작음 | 신중, 관찰력, 집중력. 속을 잘 안 보임 |
| 눈_세로 | 가늘다 | 봉안(鳳眼) 계열. 냉철, 판단력 |
| | 둥글다 | 순수, 호기심, 정이 많음 |
| 눈_사이 | 넓음 | 너그럽고 시야가 넓다. 대신 세밀함은 약할 수 있음 |
| | 좁음 | 집중력, 전문성. 예민함 주의 |
| 눈꼬리 | 올라감 | 적극적, 승부욕, 리더십 |
| | 처짐 | 온화, 배려, 인기. 우유부단 주의 |

### 눈썹 — 보수관(保壽官). 형제·인간관계
| 항목 | 등급 | 풀이 |
|---|---|---|
| 눈썹_길이 | 김 (눈보다 김) | 형제·친구 복, 인맥이 넓다 |
| | 짧음 | 독립심, 스스로 해결하는 편 |
| 눈썹_눈_간격 (전택궁) | 넓음 | 너그러움, 부동산·가정 복 |
| | 좁음 | 성급함, 추진력. 집안일에 신경 쓸 일이 많음 |
| 미간 (인당·명궁) | 넓음 | 낙천적, 도량이 크다. 운의 통로가 열린 상 |
| | 좁음 | 꼼꼼, 걱정이 많음. 한 우물형 |

### 코 — 심판관(審辨官). 재백궁, 중년 재물·자존심
| 항목 | 등급 | 풀이 |
|---|---|---|
| 코_길이 | 김 | 자존심·책임감, 중년 재물. 명예 중시 |
| | 짧음 | 유연, 친화력. 재물은 모으는 습관이 중요 |
| 콧방울_폭 | 넓음 | 재물을 담는 창고가 크다. 수완, 저축력 |
| | 좁음 | 담백, 욕심이 적음. 씀씀이 관리 필요 |

### 입 — 출납관(出納官). 식록·말
| 항목 | 등급 | 풀이 |
|---|---|---|
| 입_크기 | 큼 | 활동력, 사교성, 먹을 복(식록) |
| | 작음 | 신중, 말조심, 섬세함 |
| 입술_두께 | 두툼 | 정이 많고 인정 넘침 |
| | 얇음 | 이성적, 말이 정확함. ⚠ 웃는 사진이면 얇게 측정됨 |
| 인중_길이 | 김 | 인내·끈기, 자녀 복, 장수 상징 |
| | 짧음 | 급한 기질, 빠른 결단 |

### 턱 — 지각(地閣). 말년·아랫사람
| 등급 | 풀이 |
|---|---|
| 넓고 두툼 | 말년 안정, 부하·자녀 덕, 터전 |
| 보통 | 무난한 말년 |
| 뾰족 | 감각적, 예술성. 말년은 스스로 기반을 다져야 함 |

### 귀 — 채청관(採聽官). 엔진 미측정
사진에서 귀가 보이면 눈으로 본다: 크고 두툼한 귓불 = 복·재물, 눈썹보다 높이 붙은 귀 = 총명, 얼굴 정면에서 귀가 안 보일 만큼 붙은 귀 = 조용한 실속.

## 4. 좌우 대칭

| 등급 | 풀이 |
|---|---|
| 좋음 | 기운이 고르게 흐른다. 인생 균형 |
| 보통 | 무난 |
| 치우침 | 한쪽으로 쏠린 재능. 관상에서 흠이라기보다 개성. ⚠ 고개 돌림·표정 때문일 가능성이 크니 `warnings`를 먼저 확인 |

## 5. 풀이 순서 (출력 목차)

```
👤 관상 풀이
   ─ 측정 경고 (있으면)

1. 첫인상과 얼굴형 오행 — 한 문장 총평 + 오행 기질
2. 삼정 — 초년·중년·말년 흐름
3. 눈 — 마음과 성향
4. 눈썹·미간 — 인간관계, 운의 통로
5. 코 — 재물과 자존심
6. 입·인중·턱 — 말, 식록, 말년
7. (사주 있으면) 사주 × 관상 — 일간·용신과 얼굴형 오행의 관계
8. 마무리 — "관상은 마음 씀씀이에 따라 변한다(相由心生)" 면책
```

각 장 2~3문단. 등급을 근거로 인용한다: "콧방울이 넓은 편이라…", "삼정 중 중정이 가장 두터워…".
